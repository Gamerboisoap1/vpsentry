# VPSentry interface
The approved direction is a restrained charcoal-and-mint administration dashboard, built directly in code. Operate mode: immediate host context, honest monitoring coverage, then drill-down to the event evidence.

Inter Variable is self-hosted. Monospace is reserved for addresses, ports, timestamps and structured details. Dark green charcoal surfaces, quiet one-pixel separators, mint for healthy observations, amber for incomplete coverage, red for high-severity events. Use readable empty and error states instead of fabricated activity. Six persistent routes share the sidebar and event-detail inspector. Mobile navigation collapses; tables scroll within their panels. Animation is limited to loading indicators and brief control transitions and honors reduced motion.
